Contributing to Store API

Obrigado por considerar contribuir com a Store API! 🚀

A Store API é uma API para gerenciamento de uma loja, incluindo produtos, categorias, clientes, pedidos e estoque.

Como contribuir
1. Faça um Fork

Crie um fork deste repositório para sua conta GitHub.

2. Crie uma Branch

Crie uma branch para sua alteração:

git checkout -b feature/minha-nova-funcionalidade
3. Faça suas alterações

Implemente sua melhoria ou correção seguindo os padrões do projeto.

4. Teste suas alterações

Certifique-se de que a aplicação continua funcionando corretamente e que os testes existentes continuam passando.

5. Envie suas alterações

Faça commit das alterações:

git commit -m "feat: adiciona nova funcionalidade"

Envie para seu fork:

git push origin feature/minha-nova-funcionalidade
6. Abra um Pull Request

Abra um Pull Request descrevendo:

O que foi alterado
O motivo da alteração
Possíveis impactos
Evidências de testes (quando aplicável)
Boas práticas
Utilize nomes claros para branches e commits.
Mantenha o código limpo e organizado.
Evite alterações não relacionadas no mesmo Pull Request.
Atualize a documentação quando necessário.
Reportando problemas

Caso encontre algum bug ou tenha uma sugestão de melhoria:

Verifique se já existe uma Issue semelhante.
Caso não exista, crie uma nova Issue com o máximo de detalhes possível.
Código de Conduta

Ao participar deste projeto, espere interações respeitosas e colaborativas com todos os membros da comunidade.

Obrigado por contribuir com a Store API! 🎉
